# Reporting a security vulnerability

Send security findings about this fork directly to its maintainers through the [private vulnerability reporting form](https://github.com/LZJ-Developer/VIctory/security/advisories/new).

Include the affected branch and commit SHA (or release tag), the relevant component, the observed effect, and the smallest steps or synthetic input that reproduce it. Report the Windows and driver versions when the behavior depends on them. Keep credentials, game files, private paths and raw memory captures out of the report.

For crashes, rendering errors or performance regressions without a security impact, use the [public issue tracker](https://github.com/LZJ-Developer/VIctory/issues).
